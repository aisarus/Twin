# TWIN — Story Cut 0.6

The active website is structured as one continuous eight-scene scroll film rather than a set of independent landing-page sections.

| Scene | Dramatic function | Visual transformation | On-screen thesis |
|---|---|---|---|
| 01 / Signal | The trace survives the end of dialogue | Darkness condenses into a weak core | The conversation has ended. But something remains. |
| 02 / Origin | Reveal the scale of source material | The core unfolds into a living archive | The archive was already alive. |
| 03 / Break | Reject shallow imitation | Biography, facts and style panels rupture | A twin is not a prompt. |
| 04 / Terrain | Explain identity as a changing system | Shards become a layered mind-landscape | Identity has layers. |
| 05 / System | Give the idea technical credibility | Terrain resolves into five connected systems | Building the second self. |
| 06 / Echo | Introduce emotional imperfection | The system produces a familiar but unstable face | It sounded familiar. |
| 07 / Ascent | Turn development into a journey | The face dissolves into a route up a citadel | The route is the product. |
| 08 / Horizon | Open the future rather than claim completion | The summit blooms into a persistent network | Beyond the summit. |

## Transition grammar

- Signal → Origin: the central light intensifies and releases data upward.
- Origin → Break: the archive compresses into simplistic profile panels, then ruptures.
- Break → Terrain: fragments reorganize into illuminated topography.
- Terrain → System: strata align and become a connected machine.
- System → Echo: the central core expands into two imperfect faces.
- Echo → Ascent: facial contours become the silhouette of the mountain.
- Ascent → Horizon: the summit beam opens the sky and becomes a branching future structure.

## Production direction

The scene art uses local SVG compositions and the existing shadowed Three.js layer. A failed CDN or unavailable GPU does not block the story: the authored 2D cinematic stage remains active as a fallback.

Later production passes can replace selected foreground objects with authored GLB assets while retaining the same camera, text, transition and color choreography.
