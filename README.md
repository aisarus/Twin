# TWIN — CSS Motion Director's Cut

A single 32-second scroll-film built from inline SVG, CSS transforms and a deterministic JavaScript timeline.

## Active branch

`agent/css-motion-directors-cut`

## Files

- `SCRIPT.md` — dramatic script by second
- `SHOTLIST.md` — positions, timings and pixel specifications
- `index.html` — one archive environment and two geometric characters
- `motion.css` — art direction, CSS models, lighting, shadows and responsive framing
- `timeline.js` — scroll-to-time mapping and motion choreography
- `vercel.json` — framework-free static deployment

## Local preview

```bash
python3 -m http.server 4173
```

No expansion into later chapters until the delayed-reflection beat and the first-look beat work as a complete scene.
